# ONA Healthy — เว็บไซต์

สวนมะเขือเทศปลอดสารพิษ ONA Healthy · อำเภอพิชัย จังหวัดอุตรดิตถ์

## โครงสร้างไฟล์

```
website/
├── src/                    ← แก้ไฟล์ในนี้เท่านั้น
│   ├── sprite.html         ภาพ SVG ทั้งหมด (ใช้ร่วมทุกหน้า)
│   ├── header.html         แถบบน + เมนู + เมนูมือถือ (ใช้ร่วมทุกหน้า)
│   ├── footer.html         ท้ายหน้า (ใช้ร่วมทุกหน้า)
│   ├── page-home.html      เนื้อหาหน้าแรก
│   ├── page-products.html  เนื้อหาหน้าสินค้า
│   └── page-knowledge.html เนื้อหาหน้าความรู้
├── assets/css/style.css    ← และไฟล์นี้
├── assets/js/main.js       ← และไฟล์นี้
├── assets/video/           วิดีโอปกหน้าแรก (animation.mp4)
├── assets/img/             โลโก้ตรารับรอง (Q · OTOP · SME) ตัดมาจากสไลด์ Canva
├── index.html              สร้างอัตโนมัติ ห้ามแก้
├── products.html           สร้างอัตโนมัติ ห้ามแก้
├── knowledge.html          สร้างอัตโนมัติ ห้ามแก้
├── dist/                   ไฟล์เดียวจบสำหรับ Artifact สร้างอัตโนมัติ
├── build.py                ประกอบทุกอย่างข้างบน
└── data/                   เอกสารต้นทางของธุรกิจ (.docx)
```

**แก้ไขที่ `src/`, `assets/css/style.css`, `assets/js/main.js` เท่านั้น**
ส่วน `index.html`, `products.html` และ `dist/` เป็นผลลัพธ์จาก `py build.py` แก้แล้วจะถูกเขียนทับ

header กับ footer อยู่ไฟล์เดียวใช้ร่วมกันทุกหน้า แก้ที่เดียวมีผลทุกหน้า

SVG sprite ถูกแทรกเข้าไปในทุกหน้าตอน build เพราะ `<use href="#id">` ต้องอยู่ในเอกสารเดียวกัน
จึงจะทำงานได้โดยไม่ต้องมีเซิร์ฟเวอร์

## เว็บมีสามหน้า

`index.html` ขายของ · `products.html` แคตตาล็อกไว้กวาดตาดู · `knowledge.html`
หน้าความรู้ฉบับยาว อธิบายว่าในผลมีอะไร และอธิบายทุกผลิตภัณฑ์พร้อมส่วนประกอบ วิธีใช้ ขนาด ราคา

**หน้าความรู้ไม่มีราคาและไม่มีปุ่มสั่งซื้อ เป็นความตั้งใจ** เพราะเป็นหน้าที่คนอ่านเพื่อทำความเข้าใจว่า
ของแต่ละชิ้นคืออะไร ท้ายแต่ละกลุ่มมีลิงก์เงียบ ๆ ไปหน้าผลิตภัณฑ์ ซึ่งเป็นที่สำหรับขาย
และไม่ใส่เซตรวม (box set / monthly / gift set) ไว้ในหน้านี้ เพราะมันคือปริมาณของน้ำมะเขือเทศ
ไม่ใช่ของที่มีคุณสมบัติของตัวเอง

**แต่ขนาดบรรจุยังอยู่ทั้งสองหน้า ถ้าแก้ขนาดต้องแก้ให้ครบ** เพราะไม่มีไฟล์ข้อมูลกลาง

หน้าความรู้เข้าถึงได้จากปุ่มท้ายเซกชัน "ทำไมต้อง ONA HEALTHY" ในหน้าแรก ยังไม่ได้ใส่ในเมนูด้านบน

**แถบสารบัญของหน้าความรู้ต้องเป็นลูกโดยตรงของ `<main>` ห้ามเอาไปไว้ในเซกชัน** เพราะ
`position:sticky` จะเกาะอยู่เฉพาะตอนที่กล่องแม่ของมันยังอยู่บนจอ ถ้าอยู่ในเซกชันแรกมันจะหายไป
ทันทีที่เลื่อนพ้นเซกชันนั้น ซึ่งคือจังหวะที่หน้ายาว 30,000px เริ่มต้องใช้มันพอดี และต้องเกาะที่
`var(--topbar-h)` ไม่ใช่เลข 78 ตายตัว เพราะแถบประกาศคลี่ออกตอนเลื่อนแล้วความสูงรวมเปลี่ยน

## ดูเว็บในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าอยากให้เหมือนโฮสต์จริง:

```bash
py -m http.server 8899
```

แล้วเปิด <http://localhost:8899>

## สร้างไฟล์เดียวจบ

```bash
py build.py
```

**วิดีโอปกไม่ติดไปกับไฟล์นี้** เพราะ Artifact เป็นไฟล์เดียวจบและโหลดไฟล์ภายนอกไม่ได้
เปิดใน Artifact แล้วหน้าปกจะเหลือแต่พื้นครีมเปล่า ถ้าจะแชร์ให้คนอื่นดูหน้าปกจริง
ต้องเอาขึ้นโฮสต์ (ดูหัวข้อถัดไป) ไม่ใช่ Artifact

จะได้ `dist/ona-healthy.html` ซึ่งรวม CSS และ JS เข้าไปในไฟล์เดียว ใช้สำหรับ
Claude Artifact ที่โหลดไฟล์ภายนอกไม่ได้ ไฟล์นี้ไม่มี `<!doctype>`/`<html>`/`<head>`/`<body>`
เพราะ Artifact ห่อให้เอง — ถ้าจะเปิดดูตรง ๆ ต้องห่อ `<meta charset="utf-8">` เพิ่ม

## เอาขึ้นโฮสต์จริง

อัปโหลด `index.html` พร้อมโฟลเดอร์ `assets/` ขึ้นโฮสต์ใดก็ได้ ไม่ต้อง build
(โฟลเดอร์ `assets/video/` ต้องไปด้วย ไม่งั้นหน้าปกจะไม่มีวิดีโอ)
(ฟอนต์โหลดจาก Google Fonts จึงต้องต่ออินเทอร์เน็ต)

## ระบบสองภาษา

ไทยคือภาษาที่เขียนอยู่ในมาร์กอัปจริง อังกฤษเก็บไว้ในแอตทริบิวต์ข้างๆ ดังนั้นถ้า
ปิด JavaScript หน้าเว็บยังอ่านเป็นภาษาไทยได้ครบ

| แอตทริบิวต์ | ใช้เมื่อ |
|---|---|
| `data-en` | อิลิเมนต์ที่มีแต่ข้อความล้วน (ส่วนใหญ่ใช้อันนี้) |
| `data-en-html` | ข้างในมีแท็กปน เช่น `<br>` |
| `data-en-text` | มีทั้งข้อความและแท็กลูก เช่นปุ่มที่มีไอคอน |
| `data-en-aria` | ข้อความสำหรับ screen reader |
| `data-en-placeholder` | ช่องกรอกข้อมูล |

**เพิ่มข้อความใหม่ต้องใส่คำแปลด้วยเสมอ** ไม่งั้นสลับภาษาแล้วจะเหลือภาษาไทยค้าง
ตรวจได้เร็วๆ ด้วยการสลับเป็นอังกฤษแล้วมองหาตัวอักษรไทยที่ยังโผล่อยู่

ภาษาที่เลือกจำไว้ใน `localStorage` คีย์ `ona-lang` ถ้ายังไม่เคยเลือก จะเดาจาก
ภาษาของเบราว์เซอร์

## การจัดตัวอักษรภาษาไทย

ไทยกับอังกฤษใช้ขนาดเดียวกันทั้งเว็บ ซึ่งทำให้ไทยเสียเปรียบ เพราะพยางค์ไทยซ้อนได้ถึงสี่ชั้น
(สระล่าง–พยัญชนะ–สระบน–วรรณยุกต์) ส่วนอังกฤษไม่มีอะไรอยู่เหนือตัวอักษรเลย มีกฎเฉพาะภาษาไทย
อยู่ในบล็อก `READING IN THAI` ท้ายไฟล์ CSS ทั้งหมดผูกกับ `:root[data-lang="th"]`
**หน้าภาษาอังกฤษไม่ได้รับผลกระทบ**

- **ป้ายตัวเล็กมีขนาดขั้นต่ำ** ต่ำกว่า 12px วรรณยุกต์กับสระบนจะเบลอรวมกันจนอ่านไม่ออก
  ปรับ `.jrail__i span` 10 → 12, `.badge` กับ `.cert__s` 10.5 → 12,
  `.ft__cols h4` 11 → 12, `.ft__bot` 11.5 → 12.5
- **เอาระยะห่างตัวอักษรออก** การจัด letter-spacing กว้าง ๆ เป็นเทคนิคของอักษรละติน
  พอใช้กับไทยมันจะดึงวรรณยุกต์ห่างจากพยัญชนะที่มันเกาะอยู่ ทำให้ต้องอ่านทีละตัว
  `.eyebrow` ลดจาก .24em เหลือ .06em เฉพาะภาษาไทย

**เวลาจะเพิ่มรายการในลิสต์นี้ ให้วัดจากหน้าเว็บจริง อย่าดูจากตัวเลขในไฟล์ CSS** —
รอบแรกใส่ไป 3 ตัวโดยดูจาก CSS ว่าเขียน 11px แต่พอวัดจริงมันเป็น 12px ขึ้นไปอยู่แล้ว
และกฎ `.scard__t` ทำให้ไทย**เล็กกว่า**อังกฤษ

## หมายเหตุด้านเทคนิค

- **คอลัมน์เนื้อหาจำกัดความกว้างที่ 1580px** (`--shell-max`) เกินจากนั้นจะจัดกึ่งกลาง
  แล้วปล่อยที่เหลือเป็นขอบ เพื่อไม่ให้บรรทัดยาวเต็มจอกว้างจนอ่านล้า ส่วน hero
  กับการ์ดสินค้าเด่นยังเต็มจอ เพื่อให้เห็นความต่างระหว่าง "หน้าปก" กับ "เนื้อหา"
  ส่วน "จากไร่สู่ขวด" "เยือนสวน" และท้ายหน้าก็เต็มจอ เพราะเป็นฉากและฐานของหน้า
  รางการ์ดใน "ทำไมต้อง ONA HEALTHY" ถูกตัดที่ขอบคอลัมน์ (กรอบอยู่ที่ `.rail__wrap`)
- **ธีมสว่างอย่างเดียว** ตั้งใจไม่ทำ dark mode เพราะตัวตนของแบรนด์คือหน้าร้านสีขาว
  ทั้งหมด ถ้าปล่อยให้สลับเป็นธีมมืดจะสื่อสารแบรนด์ผิด
- **ฟอนต์สลับตามภาษา** Playfair Display กับ Poppins ไม่มีอักขระไทย โหมดไทยจึงใช้
  Trirong กับ IBM Plex Sans Thai ส่วนโลโก้และป้ายตัวพิมพ์ใหญ่ใช้ Playfair/Poppins
  ทั้งสองภาษาเพราะเป็นอักษรละตินอยู่แล้ว ควบคุมผ่านตัวแปร `--font-display`,
  `--font-body`, `--font-brand`, `--font-label`
- **`setLang()` ต้องถูกเรียกท้ายไฟล์ JS เท่านั้น** เคยย้ายไปเรียกตอนต้นแล้วสคริปต์
  ตายทั้งไฟล์ เพราะมันไปแตะตัวแปรที่ยังไม่ถูกกำหนดค่า ทำให้ฟิลเตอร์ แท็บ และ
  carousel หยุดทำงานทั้งหมดโดยไม่มีอาการฟ้องชัดเจน
- **วิดีโอปกเต็มหน้าจอทุกขนาด ครอปเอา และตัวหนังสือวางบนวิดีโอตรง ๆ ไม่มีอะไรคั่น**
  เป็นการตัดสินใจของเจ้าของเว็บ หลังจากลองมาสามแบบแล้วถูกตีกลับทุกแบบเพราะกลบวิดีโอ
  **ราคาที่ต้องจ่าย** วัดจากกรอบตัวอักษรจริงตลอดคลิป: หัวเรื่องเฉลี่ย 6.3:1 แต่ **27.5%
  ของพื้นที่ข้างหลังต่ำกว่า 4.5:1** ต่ำสุด 1.0:1 ส่วนคำโปรยเฉลี่ย 5.8:1 ต่ำกว่าเกณฑ์ 27.7%
  และจุดพวกนี้ขยับไปมาตามที่คลิปเล่น ตัวหนังสือจึงจมหายแล้วโผล่กลับมา ซึ่งดูจากภาพนิ่งไม่ค่อยเห็น
  **ทางแก้ที่ถูกต้องคือไปเกรดคลิปให้ซีดลงตั้งแต่ต้นทาง** ไม่ใช่เพิ่มม่านใน CSS อีก
- **จอแนวตั้งเห็นแค่ประมาณ 27% ของความกว้างคลิป** (เห็นแต่กระปุก ไม่เห็นโรงเรือน) อันนี้ตั้งใจ
- **`width:100%` ที่ `.hero__in` ห้ามลบ** เพราะ `.g` มี `margin-inline:auto` ซึ่งทำให้ flex item
  ไม่ยืดเต็ม คอลัมน์ทั้ง 22 จะยุบ แล้วตัวหนังสือจะเหลือกว้างไม่กี่พิกเซลติดขอบซ้าย เหมือนหายไปเลย
- **อะไรที่ต้องอยู่เหนือวิดีโอ ต้องมี `position` กับ z-index** เพราะ `.hero__panel` เป็น
  absolute z-index 0 ซึ่งจะทับเนื้อหาที่เป็น static ทั้งหมด หายไปเงียบ ๆ ไม่มี error
- **วิดีโอปกเล่นรอบเดียวแล้วค้างที่เฟรมสุดท้าย ห้ามใส่ `loop` กลับเข้าไป** เพราะวัดแล้ว
  รอยต่อจากเฟรมสุดท้ายกลับไปเฟรมแรกกระโดดแรงกว่าการเคลื่อนไหวในคลิปเอง ถ้าวนจะเห็นภาพ
  กระตุกทุก 8 วินาที และเฟรมสุดท้ายคือช็อตที่สวยที่สุดในคลิป
- **วิดีโอเล่นให้ทุกคนรวมถึงคนที่ตั้งค่าลดการเคลื่อนไหว** เป็นการตัดสินใจของเจ้าของเว็บ ไม่ใช่ลืม
  ตำแหน่งที่จะใส่กลับเขียนคอมเมนต์ไว้ใน `main.js` แล้ว
- **`body { overflow-x: clip }` ห้ามเปลี่ยนเป็น `hidden`** เพราะ `hidden` จะบังคับให้
  `overflow-y` กลายเป็น `auto` ทำให้ body เป็น scroll container แล้ว scroll event
  จะไม่ยิง ส่วน "จากไร่สู่ขวด" ที่ตรึงหน้าจอจะค้างอยู่ขั้นแรกตลอด
- **ความสูงแถบบนเป็นตัวแปร** `--hdr-h` คงที่ 78px ส่วน `--topbar-h` JS วัดค่าจริง
  แล้วอัปเดตให้ เพราะแถบประกาศคลี่ออกตอนเลื่อน ทำให้ความสูงรวมเปลี่ยน
- **ส่วนที่ตรึงหน้าจอขับด้วย `requestAnimationFrame`** ไม่ใช่ scroll event เพราะ
  เบราว์เซอร์มือถือมักรวบหรือทิ้ง scroll event ระหว่างเลื่อนแบบมีแรงเฉื่อย
  มีตาข่ายรองอีกสองชั้นคือ `scroll` และ `scrollend`
- **สองเซกชันใช้รูปแบบสลับกันโดยตั้งใจ** — "ทำไมต้อง ONA HEALTHY" ใช้รางเลื่อน
  แนวนอน (`.rail`) เพราะต้องอ่านเร็วเข้าใจประโยชน์ทันที ส่วน "หนึ่งวันที่สวน" ใช้
  แท็บ (`.tabsec`) เพราะเนื้อหาโปรโมทท่องเที่ยวต้องการพื้นที่ต่อจุดมากกว่า
  แท็บเลื่อนเองทุก 3 วินาทีและวนไม่หยุด ไม่หยุดแม้เอาเมาส์ไปวางหรือกดแท็บเอง
  หยุดเฉพาะตอนเลื่อนออกนอกจอหรือสลับไปแท็บเบราว์เซอร์อื่นเท่านั้น
  ชื่อคลาสตั้งตาม **รูปแบบ** ไม่ใช่ชื่อเซกชัน จะได้สลับได้อีกโดยไม่ต้องแก้ชื่อ
- **รางเลื่อนใช้ `scroll-snap-type: x proximity` ห้ามเปลี่ยนเป็น `mandatory`**
  เพราะ mandatory จะขัดกับการเลื่อนด้วยสคริปต์ ทำให้ปุ่มลูกศรเด้งกลับ และต้องมี
  `scroll-padding-left` เท่ากับ gutter ไม่งั้นรางจะไม่หยุดที่ scrollLeft 0
- **ปุ่มลูกศรของรางเลื่อน tween เอง** ไม่ใช้ `scrollTo({behavior:'smooth'})`
  เพราะไม่น่าเชื่อถือบนคอนเทนเนอร์ที่มี scroll-snap และมี `setTimeout` สำรอง
  เผื่อเบราว์เซอร์ไม่ส่งเฟรมให้ (เช่นแท็บพื้นหลัง) ใช้ ease-in-out 680ms
- **ระหว่าง tween ต้องปิด scroll-snap ชั่วคราว** (`scrollSnapType = 'none'`)
  ไม่งั้นเบราว์เซอร์จะดึงเข้าหาจุด snap ทุกเฟรมจนการเลื่อนกระตุก แล้วคืนค่าเมื่อจบ

  ควรตรวจสอบกับทางสวนก่อนเผยแพร่จริง
