## ต้องรันอะไรบ้าง (3 คำสั่ง)

เปิด **PowerShell ธรรมดา** บน Windows

### 1. โอนสคริปต์เข้า VM

```
type C:\Users\User\Desktop\IT-DKHL\install-erpnext.sh | ssh frappe@127.0.0.1 -p 2222 "cat > ~/install.sh && sed -i 's/\r$//' ~/install.sh && chmod +x ~/install.sh && echo OK"
```

```
type C:\Users\User\Desktop\IT-DKHL\setup-extras.sh | ssh frappe@127.0.0.1 -p 2222 "cat > ~/setup-extras.sh && sed -i 's/\r$//' ~/setup-extras.sh && chmod +x ~/setup-extras.sh && echo OK"
```

### 2. ติดตั้ง ERPNext (30–45 นาที)

```
ssh frappe@127.0.0.1 -p 2222 -t "~/install.sh"
```

จะถาม 2 รหัสตอนขั้นที่ 5 — รหัส root ฐานข้อมูล และรหัส Administrator ของ ERPNext

**ถ้าพัง** สคริปต์จะหยุดทันทีและบอกว่าค้างขั้นไหน (เช่น `หยุดที่ขั้น: 2/9 ...`)
ก๊อปข้อความส่งให้ Claude ดู อย่ารันซ้ำมั่ว ๆ

### 3. ตั้งให้รันอัตโนมัติ + สำรองข้อมูล

```
ssh frappe@127.0.0.1 -p 2222 -t "~/setup-extras.sh"
```

หลังจากนี้ ERPNext จะทำงานเองตลอด แม้ปิด SSH หรือรีบูต VM

**เปิดใช้งาน:** http://localhost:8080 → ล็อกอิน `Administrator`

## เรื่องที่ต้องตัดสินใจเอง ผมเดาแทนไม่ได้

1. **ราคาสินค้ายังไม่ยืนยัน** ตัวเลขใน CSV มาจากเพจ Facebook และโบรชัวร์ เอกสารของสวนเองเขียนว่า
   *"Prices move. Confirm with the owner"* — **ตรวจกับเจ้าของสวนก่อนใช้จริง**

2. **วันหมดอายุยังไม่ครบ** ใส่ให้เฉพาะที่มีหลักฐาน — น้ำมะเขือเทศ 365 วัน สบู่ 730 วัน
   ที่เหลือเว้นว่างไว้ **ต้องกรอกจากฉลากจริง** ไม่ควรเดา เพราะเป็นสินค้าอาหารและเครื่องสำอาง

3. **Essence แยกเป็น 2 รายการ** (มะเขือเทศ / แตงกวา) เพราะเป็นคนละ SKU แม้ราคาเท่ากัน
   ถ้าสวนนับเป็นตัวเดียวให้ลบออกหนึ่งบรรทัด

4. **ราคาโปรโมชั่นยังไม่ได้ใส่** (น้ำ 50, สบู่ 49, เม็ด 299, essence 189)
   ควรทำเป็น Pricing Rule ใน ERPNext ไม่ใช่แก้ราคาหลัก จะได้เห็นส่วนลดในรายงาน

5. **มะเขือเทศสด ตั้งราคา 0** เพราะเอกสารระบุว่า "สอบถามราคา"

## ความปลอดภัย — ทำเมื่อว่าง

รหัสผ่าน `awakasu` ถูกพิมพ์ลงประวัติแชทไปแล้ว **ควรเปลี่ยนทั้ง 3 ตัว**

```
passwd                                    # รหัส Linux
sudo mariadb-secure-installation          # รหัส root ฐานข้อมูล
bench --site erpnext.local set-admin-password   # รหัส Administrator ของ ERPNext
```

ยังไม่เร่งด่วนเพราะระบบเข้าถึงได้เฉพาะเครื่องคุณเครื่องเดียว (`127.0.0.1`)
คนอื่นในวงไวไฟมองไม่เห็น แต่ควรทำก่อนใส่ข้อมูลลูกค้าจริง

## คำสั่งที่ใช้บ่อย

```
ssh frappe@127.0.0.1 -p 2222              เข้า VM
sudo systemctl status erpnext             ดูว่า ERPNext ทำงานอยู่ไหม
sudo systemctl restart erpnext            รีสตาร์ท
sudo journalctl -u erpnext -f             ดู log สด ๆ
~/backup-erpnext.sh                       สำรองข้อมูลทันที
ls -lh ~/backups/                         ดูไฟล์สำรอง
```
