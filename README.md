```

├── website/            เว็บไซต์ ONA Healthy  (แก้ที่ src/ แล้วรัน py build.py)
├── erpnext/            ระบบ ERP ของสวน
│   ├── setup/          สคริปต์ติดตั้งและตั้งค่าเซิร์ฟเวอร์
│   ├── data/           ไฟล์นำเข้าสินค้า
│   ├── scripts/        สคริปต์สร้างข้อมูลในระบบ (รันไปแล้วทั้งหมด)
│   ├── brand/          โลโก้ที่ใช้ในระบบ
│   └── docs/           คู่มือและสคริปต์นำเสนอ
```

## เว็บไซต์ — `website/`

เว็บไซต์ ONA Healthy สองภาษา ดูรายละเอียดใน `website/README.md`

**แก้ที่ `src/`, `assets/css/style.css`, `assets/js/main.js` เท่านั้น** แล้วรัน `py build.py`

---

## ระบบ ERP — `erpnext/`

ติดตั้งอยู่ใน VirtualBox บนเครื่องนี้ **ไม่ได้อยู่บนอินเทอร์เน็ต**

### เปิดใช้งาน

1. เปิด VirtualBox กด **Start** ที่ VM ชื่อ `erpnext` (ถ้ายังไม่เปิด)
2. รอ 1 นาที แล้วเปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

ระบบตั้งให้รันเองตั้งแต่เปิดเครื่อง ไม่ต้องสั่งอะไร

### สิ่งที่อยู่ในระบบแล้ว

| | |
|---|---|
| บริษัท | ONA Healthy · THB · Asia/Bangkok |
| สินค้า | 17 รายการ — สายสุขภาพ 7 · สายผิว 8 · วัตถุดิบ 2 |
| สูตรการผลิต | น้ำมะเขือเทศ Onato 1 สูตร |
| ล็อตสินค้า | 2 ล็อต พร้อมวันหมดอายุ |
| ตัวอย่างการขาย | ใบสั่งขาย 1 · ใบส่งของ 1 |

### เข้าไปที่เครื่อง ERP

```
ssh frappe@127.0.0.1 -p 2222
```

### คำสั่งที่ใช้บ่อย

```
sudo systemctl status erpnext      ดูสถานะ
sudo systemctl restart erpnext     รีสตาร์ท
sudo journalctl -u erpnext -f      ดู log สด
~/backup-erpnext.sh                สำรองข้อมูลทันที
ls -lh ~/backups/                  ดูไฟล์สำรอง
```

สำรองข้อมูลอัตโนมัติทุกวันตี 2 เก็บย้อนหลัง 7 วัน

### การส่งออกไฟล์ — ภาษาไทย

**แก้ครบทุกจุดแล้ว** CSV และ Excel อ่านภาษาไทยได้ทั้งคู่

Frappe ส่งออก CSV โดยไม่ใส่ BOM ทำให้ Excel บน Windows อ่านภาษาไทยเป็นตัวขยะ
มีการแก้ไขโค้ด **7 จุด** ทุกจุดมีคอมเมนต์ `ONA Healthy` กำกับไว้

| ไฟล์ | ใช้กับปุ่มไหน |
|---|---|
| `frappe/desk/utils.py` | ส่งออกรายงาน + หน้า List |
| `frappe/utils/response.py` | ส่งออกทั่วไป |
| `frappe/core/doctype/data_export/exporter.py` | เขียนไฟล์ลงดิสก์ |
| `frappe/core/doctype/prepared_report/prepared_report.py` | รายงานที่ทำเบื้องหลัง |
| `frappe/core/doctype/data_import/data_import.py` | แม่แบบนำเข้าข้อมูล |
| `frappe/public/js/frappe/utils/tools.js` (2 จุด) | **ปุ่ม Download ในตารางย่อย + กราฟ** |

**จะหายไปถ้าอัปเดต Frappe** (`bench update`) ถ้าไทยกลับมาเป็นขยะให้แก้ซ้ำตามรายการนี้
สำรองไฟล์เดิมไว้ใน `/tmp/*.backup` (หายเมื่อรีบูต)

หลังแก้ไฟล์ `.js` ต้อง `bench build --app frappe` แล้วกด `Ctrl+Shift+R` ในเบราว์เซอร์

### ⚠️ การพิมพ์ PDF — ปุ่มดาวน์โหลดใช้ไม่ได้

ERPNext v16 สร้าง PDF ด้วย Chrome หรือ wkhtmltopdf **เครื่องนี้ไม่มีทั้งคู่**
และ `wkhtmltopdf` ถูกถอดออกจาก Ubuntu 26.04 แล้ว ติดตั้งไม่ได้

**ทางที่ใช้จริง:** เปิดเอกสาร → **Print** → กด **`Ctrl + P`** → **Save as PDF**

เบราว์เซอร์บน Windows เป็นคนวาดหน้านั้น ใช้ฟอนต์ไทยของ Windows ได้ผลดีกว่าด้วยซ้ำ

ฝั่งเซิร์ฟเวอร์เตรียมไว้พร้อมแล้ว — ติดตั้งฟอนต์ไทย 64 ตัว และสร้าง Print Style
ชื่อ `ONA Healthy Thai` ที่บังคับใช้ฟอนต์ Loma ทั้งเอกสาร (ถ้าไม่บังคับ ระบบจะสลับ
ฟอนต์กลางประโยคแล้วสระกับวรรณยุกต์หลุดตำแหน่ง เช่น `ราคา` กลายเป็น `ร้ำค้ำ`)

## `_unused/` — ลบได้

`erpnext-develop/` (156 MB) คือซอร์สโค้ด ERPNext ที่โหลดมาตอนแรก เป็น branch `develop`
ซึ่งเป็นรุ่นที่ยังพัฒนาไม่เสร็จ **ใช้กับข้อมูลจริงไม่ได้** และระบบที่ติดตั้งจริงไม่ได้ใช้ไฟล์ชุดนี้
(ตัวที่ใช้จริงคือ v16 เวอร์ชันเสถียร ซึ่งอยู่ในเครื่อง VM)

ลบทั้งโฟลเดอร์ได้เลยถ้าต้องการพื้นที่คืน 156 MB

## เรื่องที่ยังค้าง

1. **ตัวเลขต้นทุนเป็นค่าสมมติ** — ต้องชั่งจริง 3 ตัว: มะเขือเทศ 1 กก. ได้กี่ขวด, ราคามะเขือเทศต่อกิโล, ราคาขวดกับฉลาก
2. **ราคาขายต้องให้เจ้าของสวนยืนยัน** — ที่ใส่มาจากเพจ Facebook และโบรชัวร์
3. **วันหมดอายุใส่ได้ 5 จาก 15 รายการ** — ที่เหลือต้องดูจากฉลากจริง
4. **ยังไม่ได้ทำฝั่งบัญชีและภาษี** — ตั้งใจเว้นไว้ ต้องคุยกับสำนักงานบัญชีก่อน
5. **รหัสผ่านควรเปลี่ยน** ก่อนใส่ข้อมูลลูกค้าจริง — ดูวิธีใน `erpnext/docs/บันทึกการติดตั้ง.md`
