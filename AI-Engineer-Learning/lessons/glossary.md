# อภิธานศัพท์ AI Engineering (อังกฤษ → ไทย)

อ่านคู่กับบทเรียน เมื่อเจอคำที่ไม่คุ้น

| คำศัพท์ | ความหมาย | บท |
|---|---|---|
| **Agent** | ระบบที่ LLM ตัดสินใจเองว่าจะใช้เครื่องมืออะไร วนทำจนงานเสร็จ | 4 |
| **Agent harness** | โครงสร้างรอบตัวโมเดล: ลูป เครื่องมือ context permission memory | 4–6 |
| **API key** | รหัสลับสำหรับเรียกใช้บริการ ห้ามเปิดเผย | 1 |
| **Autoregressive** | สร้างข้อความทีละ token โดยใช้ผลก่อนหน้าเป็น input | 1 |
| **Batch API** | ส่งงานจำนวนมากแบบไม่ต้องได้ผลทันที ถูกลง 50% | 12 |
| **BM25** | อัลกอริทึมค้นหาด้วยคำ (keyword) | 7–8 |
| **Caching (prompt caching)** | ให้ API จำส่วนต้นของ prompt เพื่อลดค่าใช้จ่ายและเวลา | 2 |
| **Chunk / Chunking** | ชิ้นส่วนของเอกสาร / การตัดเอกสารเป็นชิ้น | 8 |
| **Citation** | การอ้างอิงแหล่งที่มาของคำตอบ | 8 |
| **Compaction** | การสรุปบทสนทนาเก่าให้สั้นลง | 5 |
| **Context window** | จำนวน token สูงสุดที่โมเดลรับได้ในครั้งเดียว | 1, 5 |
| **Context engineering** | การเลือกว่าจะใส่อะไรเข้า context ในแต่ละรอบ | 5 |
| **Cosine similarity** | ค่าความคล้ายของเวกเตอร์สองตัว (ใกล้ 1 = คล้ายกัน) | 7 |
| **DocType** | ประเภทเอกสารหรือตารางข้อมูลใน Frappe/ERPNext | 9 |
| **docstatus** | สถานะเอกสาร ERPNext: 0 ร่าง, 1 ยืนยัน, 2 ยกเลิก | 9 |
| **Effort** | ระดับความทุ่มเทของโมเดล (low → max) | 1 |
| **Embedding** | เวกเตอร์ตัวเลขที่แทนความหมายของข้อความ | 7 |
| **Eval (evaluation)** | ชุดทดสอบวัดคุณภาพของระบบ AI | 2, 12 |
| **Error analysis** | การจัดกลุ่มและนับสาเหตุที่ระบบทำผิด | 12 |
| **Exfiltration** | การลักลอบส่งข้อมูลออกนอกระบบ | 6 |
| **Few-shot** | การใส่ตัวอย่างใน prompt | 2 |
| **Fine-tuning** | การเทรนโมเดลเพิ่มด้วยข้อมูลของเรา | 8 |
| **Fallback** | โมเดลสำรองที่ทำงานแทนเมื่อโมเดลหลักปฏิเสธ | 1, 6 |
| **Guardrail** | กลไกป้องกันไม่ให้ระบบทำสิ่งที่ไม่ควรทำ | 6 |
| **Hallucination** | การที่โมเดลแต่งข้อมูลที่ไม่มีจริง | 1 |
| **HNSW** | โครงสร้างดัชนีสำหรับค้นหาเวกเตอร์ใกล้เคียงอย่างรวดเร็ว | 7 |
| **Human-in-the-loop** | ให้คนตรวจหรืออนุมัติก่อนระบบทำงานสำคัญ | 6, 11 |
| **Hybrid search** | การค้นหาแบบ keyword ร่วมกับ vector | 7 |
| **Knowledge cutoff** | วันที่ข้อมูลที่ใช้ฝึกโมเดลสิ้นสุด | 1 |
| **Latency** | เวลาตอบสนอง | 12 |
| **Least privilege** | ให้สิทธิ์เท่าที่จำเป็นเท่านั้น | 6 |
| **LLM** | Large Language Model: โมเดลภาษาขนาดใหญ่ | 1 |
| **LLM-as-judge** | ใช้ LLM ให้คะแนนคำตอบของ LLM | 12 |
| **MCP** | Model Context Protocol: มาตรฐานเชื่อม AI กับเครื่องมือ | 10 |
| **Memory** | ความจำข้าม session ที่เก็บไว้ในไฟล์หรือฐานข้อมูล | 5 |
| **Metadata** | ข้อมูลประกอบ เช่น แหล่งที่มา วันที่ สิทธิ์ | 7 |
| **Observability** | ความสามารถในการดูว่าระบบทำอะไรอยู่ (log, trace) | 12 |
| **Parallel tool use** | การเรียกหลายเครื่องมือพร้อมกันในรอบเดียว | 3 |
| **PDPA** | พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคลของไทย | 6 |
| **Prompt** | ข้อความคำสั่งหรือคำถามที่ส่งให้โมเดล | 2 |
| **Prompt injection** | การฝังคำสั่งแอบแฝงในข้อมูลเพื่อหลอก AI | 6 |
| **RAG** | Retrieval-Augmented Generation: ค้นข้อมูลก่อนแล้วค่อยตอบ | 8 |
| **Rate limit** | การจำกัดจำนวน request ต่อช่วงเวลา (HTTP 429) | 12 |
| **ReAct** | รูปแบบ Reason + Act: คิด → ทำ → สังเกต วนซ้ำ | 4 |
| **Recall@k** | สัดส่วนคำถามที่เอกสารที่ถูกต้องอยู่ใน k อันดับแรก | 7 |
| **Refusal** | การที่โมเดลปฏิเสธคำขอ | 1, 6 |
| **Regression** | สิ่งที่เคยทำงานได้ แต่พังหลังแก้ไข | 12 |
| **Reranking** | การจัดอันดับผลค้นหาใหม่ด้วยโมเดลที่แม่นยำกว่า | 7 |
| **REST API** | รูปแบบ API ผ่าน HTTP (GET/POST/PUT/DELETE) | 9 |
| **RRF** | Reciprocal Rank Fusion: วิธีรวมอันดับจากหลายระบบค้นหา | 7 |
| **Sandbox** | สภาพแวดล้อมที่จำกัดสิทธิ์ เพื่อไม่ให้กระทบระบบจริง | 4, 6 |
| **Schema (JSON Schema)** | ข้อกำหนดโครงสร้างข้อมูล JSON | 2, 3 |
| **SDK** | ไลบรารีสำเร็จรูปสำหรับเรียกใช้ API | 1 |
| **SSE** | Server-Sent Events: การส่งข้อมูลทยอยจากเซิร์ฟเวอร์ | 11 |
| **Stateless** | ไม่จำสถานะระหว่างการเรียกแต่ละครั้ง | 1 |
| **stop_reason** | เหตุผลที่โมเดลหยุดตอบ | 1, 3 |
| **Streaming** | การส่งคำตอบทีละส่วน | 1, 11 |
| **Structured output** | การบังคับให้โมเดลตอบตาม schema | 2 |
| **Subagent** | agent ลูกที่มี context แยกจาก agent หลัก | 5 |
| **System prompt** | คำสั่งระดับระบบที่กำหนดบทบาทและกติกา | 1, 2 |
| **Thinking (adaptive)** | การคิดก่อนตอบ โดยโมเดลเลือกเองว่าจะคิดมากแค่ไหน | 1 |
| **Token** | หน่วยย่อยของข้อความที่โมเดลประมวลผล | 1 |
| **Tool / Function calling** | การให้โมเดลขอเรียกใช้ฟังก์ชันของเรา | 3 |
| **tool_result / tool_use** | ผลลัพธ์ของเครื่องมือ / คำขอใช้เครื่องมือ | 3 |
| **Trace** | บันทึกลำดับเหตุการณ์ทั้งหมดของคำถามหนึ่งข้อ | 12 |
| **TTFT** | Time To First Token: เวลาจนกว่าจะเห็นตัวอักษรแรก | 1, 12 |
| **Vector database** | ฐานข้อมูลสำหรับเก็บและค้นหาเวกเตอร์ | 7 |
| **Webhook** | การที่ระบบหนึ่งส่ง HTTP request แจ้งอีกระบบเมื่อเกิดเหตุการณ์ | 9, 11 |
| **Workflow** | ลำดับขั้นตอนที่โค้ดกำหนดตายตัว | 4 |
| **XSS** | Cross-Site Scripting: การฝังสคริปต์อันตรายในหน้าเว็บ | 11 |
