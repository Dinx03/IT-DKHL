# โจทย์ท้ายบทที่ 1

ทำเสร็จแล้วส่งคำตอบหรือโค้ดมาให้ Claude ตรวจได้เลย

## ส่วน A — ความเข้าใจ (ตอบด้วยภาษาของตัวเอง)
1. ทำไม LLM ถึงแต่งข้อมูลที่ไม่มีจริงได้ (hallucination) ให้อธิบายโดยใช้คำว่า "ทำนาย token ถัดไป"
2. ถ้าแชทคุยกันไปแล้ว 50 รอบ ทำไมรอบที่ 51 ถึงแพงกว่ารอบแรกมาก
3. `stop_reason` เป็น `max_tokens` แปลว่าอะไร และควรแก้อย่างไร
4. ถ้าเจอ tutorial ที่ใช้ `temperature=0.7` กับ `claude-opus-5` จะเกิดอะไรขึ้น

## ส่วน B — ลงมือเขียนโค้ด
5. **ตัวนับงบ:** แก้ `04_chat_memory.py` ให้หยุดแชทอัตโนมัติเมื่อค่าใช้จ่ายรวมเกิน $0.10
6. **เก็บประวัติ:** ให้ `04_chat_memory.py` บันทึกบทสนทนาลงไฟล์ `chat_log.json` ตอนออก
   (ใบ้: เก็บเฉพาะข้อความที่เป็น text ด้วย `text_of()` เพราะ content block แปลงเป็น JSON ตรงๆ ไม่ได้)
7. **Error handling:** ครอบ `01_first_call.py` ด้วย try/except
   ที่แยกกรณี `anthropic.AuthenticationError`, `anthropic.RateLimitError` และ `anthropic.APIConnectionError`
   แล้วลองตั้ง API key ผิดโดยตั้งใจ เพื่อดูว่าจับ error ได้จริง

## ส่วน C — เตรียม Capstone 🏗
8. เขียน **system prompt** สำหรับ "ผู้ช่วยบริหารธุรกิจ" ที่จะใช้คู่กับ ERPNext ของคุณ
   - ธุรกิจของคุณ (สมมติขึ้นได้) ขายอะไร
   - ผู้ช่วยต้องทำอะไรได้ และห้ามทำอะไร
   - ต้องตอบในรูปแบบไหน

   บันทึกลงไฟล์ `capstone_system_prompt.md` แล้วทดสอบกับ `02_system_prompt.py` ด้วยคำถาม 3 ข้อ
