# เตรียมตัวหางาน

## ตลาดงานในไทย (จากการค้นหา ก.ย. 2026)

ประกาศงาน AI Engineer / AI Developer ในไทยมักต้องการ:
- ปริญญาตรีวิศวคอม / CS / ไฟฟ้า หรือสาขาใกล้เคียง (คุณผ่านข้อนี้แล้ว)
- Python, ML framework (PyTorch) และความรู้ LLM
- ทักษะวิเคราะห์ข้อมูล และการอธิบายเรื่อง AI ให้คนที่ไม่ใช่สายเทคนิคเข้าใจ

ช่องทางหางาน:

- [JobsDB – Junior AI Developer](https://th.jobsdb.com/junior-artificial-intelligence-developer-jobs)

- [Wellfound – AI Engineer Thailand](https://wellfound.com/role/l/artificial-intelligence-engineer/thailand) (สายสตาร์ทอัพ)
- LinkedIn (ตั้ง job alert คำว่า "AI Engineer", "LLM", "GenAI", "Software Engineer AI")

> **ทิปสำคัญ:** อย่าสมัครเฉพาะตำแหน่งที่ชื่อ "AI Engineer" ตำแหน่ง **Software Engineer / Backend Developer ที่ JD มีคำว่า LLM หรือ AI** มีจำนวนมากกว่า และรับ junior ง่ายกว่า
> ตำแหน่งแรกไม่จำเป็นต้องชื่อ AI ขอแค่ได้เข้าไปทำงานเกี่ยวกับ AI ก็เพียงพอ

- [ ] มีคลิป demo สั้นของโปรเจกต์เด่น

## คำถามสัมภาษณ์ที่เจอบ่อย (ฝึกตอบให้ได้)

1. RAG คืออะไร และจะแก้ปัญหาเมื่อ RAG ตอบผิดอย่างไร
2. เมื่อไหร่ควรใช้ RAG เมื่อไหร่ควร fine-tune และเมื่อไหร่แค่ prompt ก็พอ
3. อธิบาย agent loop และบอกว่าจะป้องกัน agent วนลูปไม่จบอย่างไร
4. Prompt injection คืออะไร และป้องกันอย่างไร
5. จะวัดว่าระบบ LLM "ดีขึ้น" ได้อย่างไร (evals)
6. จะลดค่าใช้จ่ายและ latency ของระบบ LLM อย่างไร
7. เล่าโปรเจกต์ของคุณ: ปัญหาคืออะไร เลือกวิธีไหน เพราะอะไร และถ้าทำใหม่จะแก้อะไร

ข้อ 7 สำคัญที่สุด ให้ฝึกเล่าเป็นเรื่องราวให้ได้ภายใน 3 นาที
