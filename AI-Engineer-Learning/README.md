## AI Engineer ทำอะไร

AI Engineer คือคนที่ **เอาโมเดลที่มีอยู่แล้ว** (Claude, GPT, Gemini, โมเดล open-source) มาสร้างเป็นระบบที่ใช้งานได้จริง
โดย **ไม่ต้องเทรนโมเดลเองตั้งแต่ศูนย์** (งานนั้นเป็นของ ML Engineer / Research Scientist)

งานนี้จึงเป็นงาน **software engineering** มากกว่างานคณิตศาสตร์ คนจบวิศวคอมจึงได้เปรียบอยู่แล้ว

ทักษะที่ตลาดงานถามหาบ่อยที่สุดในปี 2026 มี 3 เรื่อง: **RAG, Agents และ Evaluation**

## หลักการเรียนให้ได้งานจริง

1. **สัดส่วนดูคลิป 30% ลงมือทำ 70%** ดูคอร์สจบแต่ไม่มีโปรเจกต์ บริษัทก็ยังไม่เรียก
2. **ทุกเฟสต้องมีของขึ้น GitHub อย่างน้อย 1 ชิ้น** และมี README ที่อธิบายว่าแก้ปัญหาอะไร
3. **ใบ certificate มีประโยชน์ แต่ไม่ใช่ตัวตัดสิน** โปรเจกต์ที่ demo ได้มีน้ำหนักมากกว่า
4. **ไม่ต้องรอให้เรียนครบก่อนค่อยสมัครงาน** เริ่มสมัครได้ตั้งแต่จบเฟส 2–3
5. **เขียนสรุปสิ่งที่เรียนเป็นภาษาของตัวเอง** ลง blog หรือ LinkedIn การอธิบายให้คนอื่นฟังคือวิธีเรียนที่ได้ผลที่สุด

## ข้อควรรู้เรื่องเครื่องของคุณ

- Docker ในเครื่องนี้ยังใช้ไม่ได้ เพราะยังไม่ได้ลง WSL ถ้าจะฝึก deploy ในเฟส 4 มีสองทาง:
  (ก) ลง WSL2 แล้วติดตั้ง Docker Desktop ใหม่ หรือ (ข) ใช้ VM ของ ERPNext ที่มีอยู่แล้ว
- คุณมี **ERPNext** อยู่แล้ว ซึ่งเอามาทำเป็นโปรเจกต์ portfolio ได้ดีมาก (ดูโปรเจกต์ที่ 4 ใน [02-projects.md](02-projects.md))
